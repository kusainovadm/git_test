Этот проект выполняется в рамках курса The Odin Project и направлен на отработку базовых навыков разметки с использованием только HTML. Я создаю простую структуру целевой страницы (Landing Page), сосредотачиваясь на правильном использовании семантических тегов и логической организации содержимого.

Завершив проект, я продемонстрирую следующие навыки:

Построение HTML-документа с правильной структурой (<!DOCTYPE html>, <html>, <head>, <body>);

Использование семантических элементов, таких как <header>, <main>, <section>, <article>, <footer>;

Вставка изображений с помощью тега <img> и использование атрибута alt для доступности;

Создание навигации и работу с гиперссылками (<a>);

Использование заголовков (<h1>–<h6>), параграфов (<p>), списков (<ul>, <ol>, <li>) и других базовых тегов;

Организация контента для будущей стилизации через CSS.

Этот проект закладывает прочный фундамент для понимания веб-разметки и подготовит меня к следующему этапу — изучению CSS и построению полноценного визуального интерфейса.
